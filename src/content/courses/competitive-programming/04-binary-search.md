## 核心概念

如果一個條件 $f(x)$ 具有**單調性**：存在某個分界點，在它之前都是 `false`、之後都是 `true`，就可以用二分搜尋在 $O(\log n)$ 次判斷內找到分界點。

## 在排序陣列中找值

找出排序好的陣列中，第一個 $\ge x$ 的位置：

```cpp
int lo = 0, hi = n;          // 答案在 [lo, hi] 之間
while (lo < hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] >= x) hi = mid;
    else lo = mid + 1;
}
// lo 就是第一個 >= x 的位置，若 lo == n 代表不存在
```

C++ 標準函式庫也有現成的 `lower_bound` / `upper_bound`。

## 對答案二分

很多「求最小的可行值」的題目，可以把問題改寫成：

> 給定答案 $k$，能不能做到？

只要「$k$ 可行 ⇒ 比 $k$ 大的也可行」，就能對 $k$ 二分，每次用一個 $O(n)$ 的檢查函式判斷，總複雜度 $O(n \log C)$，其中 $C$ 是答案的範圍。

### 小心邊界

- 確認 `lo`、`hi` 的初始值一定包含答案
- `mid` 的取法和更新方式要對應，否則可能無窮迴圈
