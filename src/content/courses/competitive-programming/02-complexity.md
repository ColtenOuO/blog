## 為什麼需要估算

題目通常會給時間限制，例如 1 秒。在動手寫之前先估計程式大概要執行幾次運算，就能判斷方法會不會 TLE。

## Big-O 記號

我們只關心輸入規模 $n$ 變大時，運算次數**成長的速度**，忽略常數與低次項：

$$
3n^2 + 5n + 7 = O(n^2)
$$

## 經驗法則

一般的評測機一秒大約可以做 $10^8$ 次簡單運算。依照資料範圍，可以反推出能接受的複雜度：

| $n$ 的上限 | 可以接受的複雜度 |
| --- | --- |
| $10$ | $O(n!)$ |
| $20$ | $O(2^n)$ |
| $500$ | $O(n^3)$ |
| $5000$ | $O(n^2)$ |
| $10^6$ | $O(n \log n)$ |
| $10^8$ | $O(n)$ |

## 例子

```cpp
// O(n^2)：兩層迴圈
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        cnt++;

// O(log n)：每次範圍減半
while (n > 1) n /= 2;
```

### 小練習

如果 $n \le 2 \times 10^5$，$O(n^2)$ 的解法大約要做 $4 \times 10^{10}$ 次運算，一定會超時，需要找 $O(n \log n)$ 以內的方法。
